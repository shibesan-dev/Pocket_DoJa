# Third-Party Notices

## libretro/slang-shaders

- Project: https://github.com/libretro/slang-shaders
- Purpose: Visual inspiration for the display filters available in the emulator's "Filter" settings

The display filters bundled with Pocket DoJa (Scanlines, LCD Grid, CRT, Dot Matrix,
Game Boy, Sepia, Grayscale) are independent Java implementations written for this
project, inspired by the visual appearance of classic presets in the
libretro/slang-shaders repository.

No shader source code from libretro/slang-shaders is included in this project.

The libretro/slang-shaders repository is a collection of shaders by many authors
distributed under a mix of licenses (including BSD-3-Clause, CC0-1.0, CC-BY,
GPL-2.0-or-later and others), with each shader file carrying its own terms.
Should shader code from that repository ever be incorporated into this project in
the future, the license of the individual shader file applies and should be
recorded below.

Thank you to the libretro community and all shader authors for their work
preserving the look of classic displays.
